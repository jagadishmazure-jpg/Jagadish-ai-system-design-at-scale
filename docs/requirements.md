# Requirements (Quillmoor Market support platform)

**Functional:** answer policy questions with citations, show order status to the order's owner only, issue refunds after confirmation and approval, accept partner shipment webhooks, push live order updates.

**Non-functional (targets, not measurements):** p95 under 2.5 s for chat, 5xx rate under 1%, cost under $0.01 per conversation, zero PII in traces, zero downtime on deploy, and a single-region data residency guarantee.

**Constraints:** free tier only, offline-runnable, fictional data.
