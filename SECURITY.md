# Security policy

This is a portfolio project. It uses fictional data and fake providers, and no
real secrets belong here.

**Reporting:** please use GitHub private vulnerability reporting (Security tab →
"Report a vulnerability"). Do not open a public issue. Expect a reply within 7 days.

**In scope:** auth bypass, cross-tenant or cross-user data access, guardrail
bypass that leads to an unauthorized action, limit or budget bypass, and
secrets committed to the repo.

The controls and residual risks are in [docs/threat-model.md](docs/threat-model.md).
